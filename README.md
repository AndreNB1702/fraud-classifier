# Predicting Frauds - Universidade Federal de Rondônia

This project uses the Online Payments Fraud Detection Dataset, available on Kaggle:

https://www.kaggle.com/datasets/rupakroy/online-payments-fraud-detection-dataset

The goal was to explore how Machine Learning techniques can be applied to fraud detection in the financial/banking sector.

The work includes:

Exploratory Data Analysis (EDA)

Data cleaning and preprocessing

Feature engineering

Handling class imbalance

Training and evaluation of multiple ML models

Different encoding strategies were tested (Label Encoding and One-Hot Encoding), and model performance was compared under various configurations.

This project was developed as part of a university assignment to demonstrate how Machine Learning can support fraud detection in financial systems.

# Prevendo Fraudes — Universidade Federal de Rondônia

Este projeto utiliza o Online Payments Fraud Detection Dataset, disponível no Kaggle:

https://www.kaggle.com/datasets/rupakroy/online-payments-fraud-detection-dataset

O objetivo foi explorar como técnicas de Machine Learning podem ser aplicadas à detecção de fraudes no setor financeiro/bancário.

O trabalho inclui:

Análise exploratória (EDA)

Limpeza e preparação dos dados

Engenharia de features

Tratamento de desbalanceamento

Treinamento e avaliação de diversos modelos de ML

Foram testadas diferentes estratégias de codificação (Label Encoder e One-Hot Encoding), comparando o desempenho dos modelos em diferentes cenários.

Este projeto foi desenvolvido como parte de um trabalho acadêmico para demonstrar como Machine Learning pode ser utilizado na detecção de fraudes em sistemas financeiros.
